# Guild camp illustration

`guild-camp.png` was generated for this project using the built-in image_gen tool.
It is decorative; characters in the illustration are not live session avatars.
Tkinter scales/crops the local PNG at runtime. No network service or Pillow is
required to run the panel. If the image is absent, the dashboard still works.

## Generation prompt

Use case: stylized-concept. Asset type: pixel-art background banner for a small desktop RPG guild usage dashboard. Generate a wide 3:1 panoramic illustration, ideally 1536x512. A quiet medieval adventurers' village at night, navy blue starry sky, layered pine forest and distant mountains, a tiny timber cottage with a warmly lit window on the left, crates and barrels, low grassy stone ground along the bottom. On the right half two tiny chibi pixel adventurers resting by a glowing orange campfire beside a wooden bench and a lantern. Crisp carefully placed visible pixel clusters, handcrafted 16-bit RPG game background, restrained deep navy and teal palette with golden firelight. Keep upper left and left middle very dark and sparse for UI text to overlay. Side-view game scene, intimate cozy atmosphere. Full-bleed scene only; no text, letters, numbers, logos, frames, dashboard, or UI. Render wide landscape.
